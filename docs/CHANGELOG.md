# Changelog

## 0.5.0

- Add English-to-Simplified-Chinese clipboard translation with Ctrl+E.
- Show Chinese results in a centered, resizable reader with larger text and content-aware height.
- Preserve the full translation; long text scrolls. Escape and Close hide the reader, with no automatic timeout.
- Automatically copy Chinese results and provide a Copy Full Text button that preserves the reading position.
- Keep the existing Ctrl+Q Chinese-to-English workflow and its five-second compact notification.
- Separate translation instructions and recent examples by direction; preserve existing settings and legacy history.
- Detect duplicate hotkeys and report registration status for both shortcuts.

## 0.4.1

First public release of Codex Companion Translate.

- Clipboard translation through the existing Codex CLI sign-in.
- Ctrl+Q shortcut, compact status notification, automatic clipboard replacement.
- Custom translation instructions, model settings and recent translation examples.
- Companion icon, local activity animation, brief completion check, five-second notification.
- High-DPI text, buffered painting and corrected border rendering.
- Hotkey registration diagnostics and explicit re-registration when settings reload.
