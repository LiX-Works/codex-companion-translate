# Codex Companion Translate 0.4.1

A lightweight Windows clipboard translator that works alongside an existing Codex sign-in.

Copy Chinese instructions, press **Ctrl+Q**, and paste the English translation when the completion check appears. Model settings, translation instructions and recent examples can be customized independently of the main Codex chat.

This release includes a compact notification, a companion activity animation, a short completion check and a five-second display time.

Download the Windows ZIP, extract it to a writable folder, and run `CodexClipboardTranslator.exe`. An existing Codex CLI with ChatGPT sign-in is required. The package does not include an account, credentials or API keys.

中文：复制中文指令，按 **Ctrl+Q**，完成后直接粘贴英文。可单独配置模型与翻译规则。下载 ZIP 解压后运行程序；需要已有 Codex CLI 登录。
